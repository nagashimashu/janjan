# 星翠麻雀（SEISUI MAHJONG）

ブラウザーだけで遊べる、一人用の静的Web麻雀ゲームです。
HTML・CSS・Vanilla JavaScript だけで作られており、サーバー・データベース・外部API・外部ライブラリを使いません。

> **現在の版：v0.3.0（フェーズ3）**
> 「牌操作デモ」「何切る問題（10問）」と、「CPU四人麻雀」の基本進行（ツモ・打牌・流局・東風戦の終了と順位）が遊べます。
> CPU四人麻雀では**ロン・ツモ和了、鳴き、リーチがまだできない**ため、すべての局が流局で終わります（画面にも明記しています）。

## 対応ブラウザー

最新版の Chrome／Edge／Safari／Firefox（PC・タブレット・スマートフォン）。
`<dialog>`、Web Animations API、`dvh` 単位、Pointer Events を使用します（2023年以降の主要ブラウザーはすべて対応）。

## 起動方法

1. `index.html` をブラウザーで開く（ビルド不要・`file://` でも動作）
2. または簡易サーバーで確認する（Node.js がある場合）

```bash
node tools/serve.js 8080
```

ブラウザーで `http://localhost:8080/` を開きます。`?debug=1` を付けるとデバッグパネルが表示されます。

| モード | 状態 | 内容 |
|---|---|---|
| 牌操作デモ | ✅ 遊べる | 配牌・ツモ・選択・打牌・整列・河・残り牌数・ドラ表示。テスト用の固定牌山も読み込めます |

## 操作方法

### タッチ・マウス

| 操作 | 動作 |
|---|---|
| 牌をタップ | 選択（牌が浮き上がり、上に▼が付く） |
| 選択中の牌をもう一度タップ | 打牌（打牌方法が「再タップ」のとき） |
| 牌を上へスワイプ | 打牌（小さな動きはタップ扱い。横方向の動きは手牌の横スクロール） |
| 牌を長押し | 牌の名前・赤ドラ・ドラ・ツモ牌を表示 |
| 「この牌を切る」 | 選択中の牌を打牌（どの設定でも使えます） |

**誤打牌防止**（既定オン）では、最初のタップ・スワイプは選択だけになります。オフにすると1回で打牌します。

### 何切る問題

| 操作 | 動作 |
|---|---|
| 牌をタップ | 切る候補として選択 |
| 「この牌を切る」 | 回答（打牌方法の設定により、再タップ・上スワイプでも回答） |
| 「解説を詳しく見る」 | 結果シートを広げる（手牌は隠れません） |
| 回答後に牌をタップ | その牌を切った場合と比較 |
| 前の問題／問題一覧／次の問題 | 画面下部のボタン（絞り込み中は絞り込んだ順） |

評価は「◎最有力」「○有力」「△目的によって選択可能」「✕改善余地あり」の4段階で、◎と○を正答として数えます。

### CPU四人麻雀

| 操作 | 動作 |
|---|---|
| 牌をタップ／もう一度タップ／上スワイプ／「この牌を切る」 | 打牌（牌操作デモと同じ。ツモは自動） |
| 「整列」 | 手牌を並べ直す（自動整列がオフのとき） |
| 「オート」 | あなたの手番もCPU（レベル1）が打牌する |
| メニュー（≡）→「対局を終了」 | 確認のうえ対局をやめる |

あなたの番になると手牌が光り、短く振動します（振動は設定でオフにできます）。CPUの番は、そのCPUのパネルに「考え中」と表示されます。

### キーボード

| キー | 動作 |
|---|---|
| ← → / Home / End | 手牌のフォーカス移動 |
| Enter / Space | 選択・打牌 |
| T | ツモ |
| S | 整列 |
| D | 選択中の牌を切る |
| I | フォーカス中の牌の情報 |
| N ／ P | 次／前の問題（何切る問題） |
| A | オートの切り替え（CPU四人麻雀） |

### 設定（`localStorage` に保存）

牌サイズ／打牌方法（再タップ・上スワイプ・確認ボタン）／誤打牌防止／振動／効果音／音量／演出速度（標準・高速・演出少なめ）／CPU思考時間（即時・標準・ゆっくり）／自動整列／ツモ牌を分離表示／横向き推奨表示／デバッグ表示

## 簡略化したルール

牌操作デモ（現在の版）：

- ドラ表示牌は1枚のみ（カンドラ・裏ドラなし）
- 山は1列の配列として扱い、牌山の積み方・サイコロ・取り出し位置は再現していません
- 鳴き・アガリ判定はありません

何切る問題（現在の版）：

- 受入は「シャンテン数が進む牌」だけを数えます。好形変化や打点変化（受入は増えないが形が良くなる牌）は数値に含めず、解説で補っています
- 残り枚数は、手牌14枚・ドラ表示牌・問題文の「見えている牌」だけを差し引きます（他家の手牌や河全体は考慮しません）
- 自分が4枚持っている牌の単騎待ちのような「実際には和了れない聴牌」も、シャンテン数の計算上は聴牌として扱います（受入は0枚と表示されます）
- 評価（最有力〜改善余地あり）は問題データに書かれたもので、場況の自動評価は行いません。候補に無い打牌はすべて「改善余地あり」になります

CPU四人麻雀（現在の版）：

- 和了・鳴き・リーチ・途中流局がないため、すべての局が山切れの流局で終わります。そのため親のテンパイによる連荘が続きやすく、1対局が10局前後になることがあります
- テンパイ判定は「手牌のシャンテン数が0」で行います。自分で4枚使っている牌の単騎待ち（純カラ）などもテンパイ扱いです
- 配牌は親から4枚ずつ3巡＋1枚ずつ配りますが、牌山の積み方・サイコロでの開門位置は再現していません（起家決定のみサイコロを使用）
- ドラ表示牌は1枚のみです（カンドラ・裏ドラは鳴き・リーチの実装時に追加）
- 操作の制限時間はありません
- 対局は画面を再読み込みすると失われます（画面回転では失われません）

今後の実装で予定している簡略化は [docs/DESIGN.md の「簡略化するルール」](docs/DESIGN.md#8-簡略化するルール予定) を参照してください。

## テスト方法

- ブラウザー：`tests/index.html` を開き、各テストページを表示する
- Node.js：

```bash
node tests/run-node.js
```

現在のテスト（128件）：

- 牌・牌山（`tests/tiles-tests.html`）：牌の生成（136枚・重複なし・各4枚・赤ドラ枚数）、文字列表記、ドラ表示牌、整列、牌山（枚数・シード再現・固定配牌・固定ツモ順・不正入力）、デモ進行（ツモ・打牌・ツモ切り記録・枚数保持・流局）、保存データの読み込み
- シャンテン数・受入・何切る（`tests/shanten-tests.html`）：和了・聴牌・一向聴・二向聴、七対子（4枚使い）、国士無双、副露、受入の残り枚数（見えている牌の除外）、打牌候補の並び順、全問題の形式と計算値の検証、判定、成績
- CPU四人麻雀（`tests/match-tests.html`）：起家決定、配牌（13枚×4・ツモ山70枚・王牌14枚）、手番順、ツモ切り／手出しの記録、手番以外の打牌の拒否、牌の総数136枚の保持、70回のツモでの流局、ノーテン罰符（1〜3人・全員・0人）、点数合計の保存、親テンパイの連荘と親流れ、東風戦の終了、トビ、同点の順位、CPU4人での東風戦の完走、CPUレベル1の打牌（孤立字牌・オタ風優先・端牌優先・シャンテン数を悪化させない（ランダム200手）・赤5を残す）

シャンテン数の計算は、高速化前の単純な全探索とランダムな3000手で結果が一致することを確認しています。

## 問題追加方法

問題は `data/questions.js` の `MJ.QUESTIONS` に追加します。手順は [skills/add-question.skill.md](skills/add-question.skill.md) を参照してください。

```bash
node tools/question-tool.js --hand 23456m78p345678s4z --dora 1p
```

で任意の手牌の全打牌（シャンテン数・受入）を出力できます。候補の数値は手で数えず、この出力を使ってください。`node tools/question-tool.js` で全問題を検証できます（テストでも同じ検証を行います）。

問題には必ず `reviewed`・`reviewerNote`・`lastUpdated` を付け、未レビューの問題は画面に「確認中」と表示します。**現在の10問はすべて未レビューです**（シャンテン数・受入枚数は計算で検証済みですが、評価と解説は人の確認を経ていません）。

## CPU評価ロジック

`js/cpu-player.js` にあります。現在はレベル1のみです。

| レベル | 内容 |
|---|---|
| 1 ✅ | シャンテン数を悪化させない牌だけを候補にし、その中で「残す価値」が最も低い牌を切る。残す価値＝他の牌とのつながり（同じ牌・隣・1つ飛び）＋数牌の位置（3〜7＞2・8＞1・9）＋字牌の評価（役牌は少し高く、オタ風は低く）。鳴かない |
| 2（未実装） | シャンテン数最優先・受入枚数比較・役牌／ドラ／赤ドラ評価・テンパイ時リーチ判断・役がある鳴き |
| 3（未実装） | 打点と速度の比較・リーチ者への危険度（現物・字牌・壁・筋）・点数状況・オーラスの順位条件 |

判断理由と評価値（0〜100、大きいほど「切ってよい」）はデバッグパネル（`?debug=1` または設定の「デバッグ表示」）に表示されます。

```text
CPU南（アカネ）：北を選択　理由：シャンテン数維持、孤立牌、役のない字牌　評価値：100
```

## GitHub Pages への公開

1. このフォルダーの中身をリポジトリのルート（または `docs/` 以外の任意のフォルダー）に置いてプッシュ
2. GitHub のリポジトリで **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダーを `/ (root)` にして保存
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

ビルド処理はありません。すべて相対パスで参照しているため、サブパスでも動作します。

## 著作権・素材方針

- 牌面（SVG）・エンブレム・背景・配色・画面構成は、すべて本プロジェクトのオリジナルです
- 効果音は Web Audio API で合成しており、音声ファイルは使用していません
- 既存の麻雀ゲームの画面・ロゴ・名称・キャラクター・牌画像・効果音・台詞は使用していません
- 外部画像・外部フォント・外部ライブラリは使用していません（牌の漢字は端末の明朝体で描画します）
- 保存するのは設定と成績だけで、個人情報は収集しません
