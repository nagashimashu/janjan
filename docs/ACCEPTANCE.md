# 受入条件の確認状況（v1.0.0）

制作指示（「17. 完成時の受入条件」と「7.13 スマートフォン向けテスト要件」）の各項目について、実装と確認の状況をまとめます。

- **確認済み**：自動テスト、またはブラウザー（デスクトップ幅・スマホ縦 375×812・スマホ横 812×375 の表示エミュレーション）で動作を確認した
- **構成上対応**：その条件を満たすように作ってあるが、実際の環境（実機・GitHub Pages）では確認していない
- **一部**：条件の一部だけを満たしている

> 実機（iPhone・Android）での確認と、GitHub Pages への実際の公開は行っていません。公開前に [skills/pre-release-check.skill.md](../skills/pre-release-check.skill.md) の項目を実機で確認してください。

## 完成時の受入条件

| 条件 | 状況 | 根拠・確認方法 |
|---|---|---|
| GitHub Pages で表示できる | 構成上対応 | ビルド不要・相対パスのみ・`.nojekyll` あり。簡易サーバー（`tools/serve.js`）経由の表示は確認済み。実際の公開は未確認 |
| サーバーなしで主要機能が動作する | 構成上対応 | ES Modules・`fetch`・外部通信を使わない（すべて `<script>` 読み込み）。`file://` で直接開いた動作は、検証用ブラウザーが `file://` を開けなかったため未確認 |
| 牌操作デモが滑らかに動く | 確認済み | 配牌・ツモ・打牌（回転して河へ）・整列の演出、二重打牌が起きないこと（連続タップ） |
| 何切る問題が10問以上遊べる | 確認済み | 10問。全問の計算値をテストでエンジンと照合（`tests/shanten-tests.html`）。推奨打牌と解説は**未レビュー**（画面に「確認中」） |
| CPU3人との東風戦が最後まで進行する | 確認済み | 画面で最終順位まで進行。テストとシミュレーションで、レベル1〜3の東風戦を完走（エラー0件） |
| 主要役と点数計算が動く | 確認済み | 24役、点数早見表との照合（`tests/yaku-tests.html`・`tests/scoring-tests.html`） |
| PCとスマートフォンで操作できる | 確認済み（エミュレーション） | クリック・キーボード、タッチ（Pointer Events の疑似入力）。実機は未確認 |
| スマートフォンの縦向き・横向きで主要操作ができる | 確認済み（エミュレーション） | 375×812・812×375 で、牌操作デモ・何切る問題・対局（鳴き・リーチ・結果画面）がはみ出さずに操作できる |
| タップ・再タップ・上スワイプによる牌操作ができる | 確認済み（疑似入力） | 誤打牌防止オンで「1回目は選択・2回目で打牌」、オフで1回打牌、上スワイプの閾値 |
| 主要ボタンが44×44 CSSピクセル以上 | 確認済み | 全画面のボタンを計測し44px未満なし。設定のスイッチ本体は56×32だが、行全体（高さ60以上）が押せる `label`。手牌の牌は画面幅に合わせて縮小するため幅44px未満になる（見た目より上下に広いタップ領域を確保） |
| 画面回転後も対局状態を維持できる | 確認済み（エミュレーション） | 縦→横で手牌・残り枚数・手番が変わらない。制限時間も引き継ぐ。進行は二重にならない（予約は常に1本） |
| ノッチとホームインジケーターを考慮したレイアウト | 構成上対応 | `viewport-fit=cover` と `env(safe-area-inset-*)`。実機は未確認 |
| オリジナルのビジュアル | 確認済み | 牌面SVG・エンブレム・背景・配色・名称はすべて自作 |
| 既存ゲームの素材を使用していない | 確認済み | 外部画像・音声・フォント・ライブラリなし |
| 音量調整とミュートがある | 確認済み | 設定・対局中メニューの「音量」「効果音」。実際に音が鳴ることは未確認（検証環境では音を聞けないため） |
| 戦績が localStorage へ保存される | 確認済み | 対局終了後に `seisui.stats.v1` へ保存され、戦績画面に表示されることを確認 |
| 主要ロジックにテストがある | 確認済み | 310件（ブラウザー8ページ・Node.js） |
| 未実装・簡略化ルールが明示されている | 確認済み | README「簡略化したルール」「未実装機能」、遊び方、ルール設定画面 |
| README・instructions.md・CHANGELOG.md が整備されている | 確認済み | ほかに docs/DESIGN.md、本書、skills/ の手順書 |

## スマートフォン向けテスト要件（7.13）

| 要件 | 状況 | 補足 |
|---|---|---|
| iPhone相当の狭い画面で牌を選択・打牌できる | 確認済み（375×812） | 実機は未確認 |
| Android相当の画面で牌を選択・打牌できる | 一部 | 表示幅が近い 375px で確認。Android 実機は未確認 |
| 縦向きと横向きでレイアウトが破綻しない | 確認済み（エミュレーション） | 横スクロール・縦はみ出しなし（`scrollWidth`／`scrollHeight` を計測） |
| 画面回転後も対局状態が維持される | 確認済み（エミュレーション） | |
| 上スワイプと縦スクロールが競合しない | 構成上対応 | 手牌は `touch-action: pan-x`、縦方向優勢の動きだけを打牌として扱う。実機の指操作は未確認 |
| 連続タップで同じ打牌が二重処理されない | 確認済み | 演出中は入力をロック |
| 長押し時にブラウザー標準メニューが表示されない | 構成上対応 | `contextmenu` の抑止・`-webkit-touch-callout: none`。実機は未確認 |
| ノッチとホームインジケーターにボタンが重ならない | 構成上対応 | セーフエリアの余白。実機は未確認 |
| 文字サイズ拡大時も操作可能 | 一部 | 主要ボタンは文字の大きさに合わせて伸びる作り。200%拡大での確認は未実施 |
| 片手操作で主要ボタンに届く | 構成上対応 | 主要操作（打牌・鳴き・リーチ・オート）は画面下部に集約 |
| 何切る問題の解説が手牌を完全に隠さない | 確認済み（エミュレーション） | 結果シートを広げると問題情報を畳み、手牌は残す |
| CPU四人麻雀で鳴き候補を選択できる | 確認済み | チーの組み合わせが2通りある場面で選択画面から選び、鳴き牌が表示されることを確認 |
| 音量・振動・演出速度の設定が保存される | 確認済み | `seisui.settings.v1`。振動が実際に動くことは未確認 |
| `prefers-reduced-motion` 有効時に演出が簡略化される | 構成上対応 | `matchMedia` で検出し、移動演出・粒子を省略（「演出少なめ」設定と同じ経路で、こちらは動作確認済み） |
