# スキル：公開前チェック

公開（GitHub Pages へのプッシュ）の前に、上から順に確認する。

## 自動テスト

- [ ] `node tests/run-node.js` がすべて成功する
- [ ] `tests/index.html` の各テストページがすべて成功する
- [ ] ブラウザーの開発者ツールでコンソールにエラーが出ていない

## 動作

- [ ] `index.html` を直接開いて（`file://`）起動する
- [ ] 簡易サーバー（`node tools/serve.js`）経由でも起動する
- [ ] 牌操作デモ：配牌 → ツモ → 選択 → 打牌 → 整列 → 流局まで進む
- [ ] 打牌方法（再タップ・上スワイプ・確認ボタン）と誤打牌防止のオン・オフがそれぞれ期待どおり動く
- [ ] 連続タップで二重に打牌されない
- [ ] 手牌読込で不正な入力をするとエラーが表示され、ゲームが壊れない
- [ ] `node tools/question-tool.js` で全問題が ✔ になる
- [ ] 何切る問題：選択 → 回答 → 結果シート（たたむ／広げる）→ 別の牌で比較 → もう一度解く → 次の問題、まで進む
- [ ] 何切る問題：結果シートを広げても手牌が見えている（縦向き・横向き）
- [ ] 何切る問題：成績が一覧・戦績画面に反映され、リセットで0に戻る
- [ ] 未レビューの問題に「確認中」が表示されている
- [ ] CPU四人麻雀：対局開始 → 起家決定 → 配牌 → あなたの打牌 → CPUの打牌 → 流局 → 次の局 → 最終順位、まで進む（「オート」と設定の「CPU思考時間：即時」「演出少なめ」で早送りできる）
- [ ] CPU四人麻雀：河が3段（18枚）になっても中央の正方形からはみ出さない（PC・縦・横）
- [ ] CPU四人麻雀：対局中に画面を回転しても、手牌・河・手番・残り枚数が変わらず、進行が二重にならない
- [ ] CPU四人麻雀：メニューの「対局を終了」で確認ダイアログが出る
- [ ] `?debug=1` でCPUの判断理由（例：CPU東（ヒスイ）：北を選択　理由：…　評価値：…）が表示される
- [ ] 設定を変更して再読み込みしても保持される。データ初期化で既定値に戻る

## 画面

- [ ] 幅 320px・375px の縦向きで横スクロールが出ない
- [ ] スマホ横向き（812×375 程度）で手牌とボタンが画面内に収まる
- [ ] 画面回転後も手牌・河・選択状態が維持される
- [ ] ノッチ・ホームインジケーターにボタンが重ならない（iOS 実機または Safari のシミュレーター）
- [ ] 文字サイズを200%に拡大しても主要ボタンが押せる
- [ ] OS の「視差効果を減らす」を有効にすると、移動演出と粒子が出ない
- [ ] キーボードだけで全操作ができ、フォーカス位置が見える

## 表記

- [ ] 未実装の機能が、画面と README で「未実装／準備中」と明記されている
- [ ] 簡略化したルールが README とルール設定画面に書かれている
- [ ] `CHANGELOG.md`・`data/changelog.js`・`MJ.VERSION`（`js/constants.js`）のバージョンが揃っている
- [ ] 既存作品の素材（画像・音声・ロゴ・名称）が含まれていない
